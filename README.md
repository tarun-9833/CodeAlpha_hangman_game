Re# Hangman Game – Python

A simple and interactive Hangman Game developed using Python. This project is designed as a beginner-friendly Python programming project to demonstrate basic programming concepts such as lists, strings, loops, conditional statements, user input, and the random module.

## About the Project

In this Hangman Game, the computer randomly selects one day from the seven days of the week:

- Monday
- Tuesday
- Wednesday
- Thursday
- Friday
- Saturday
- Sunday

The selected day is hidden from the player using underscores. The player has to guess the letters one by one to reveal the complete word.

The player is allowed a maximum of 6 wrong guesses. If the player guesses the complete word before reaching the maximum number of wrong attempts, they win the game. Otherwise, the game ends and the correct word is displayed.

## Features

- Randomly selects a day from Monday to Sunday
- Letter-by-letter word guessing
- Maximum 6 wrong guesses
- Prevents repeated letter guesses
- Checks for valid user input
- Displays a winning message
- Displays a game-over message
- Simple text-based interface

## Technologies Used

- Python 3
- Random module
- Lists
- Strings
- While loop
- If-else conditions
- User input
